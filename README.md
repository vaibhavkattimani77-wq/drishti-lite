# DRISHTI-lite

Pharmacovigilance research prototype for FAERS signal detection, triage and case review.
Not a validated or regulatory-compliant system; outputs are hypothesis-generating only.

Status: Phase 1 (Scientific MVP) in progress. See DRISHTI-lite_Spec_v2.md.

## Setup
    python -m venv .venv
    .venv\Scripts\activate        (Windows)   |   source .venv/bin/activate   (macOS/Linux)
    pip install -r requirements.txt
    pytest
